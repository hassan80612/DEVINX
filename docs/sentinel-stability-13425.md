# Sentinel 13.4.25

Maintaining an existing forecast no longer repeats the percentage and points
limits used to admit a new forecast. Fresh input, the planner's own directional
readiness and safety checks remain mandatory. Small score dips preserve the
original direction, trigger, confidence, ID and deadline.

The scenario can retire its own confirmed opposing price structure before a
new opposite forecast meets admission thresholds. Confirmation requires a
continuous five-bar sequence: the range of three preceding closed bars, a
break beyond that range, and a completed hold beyond the break with a lower
high or higher low. A wick, unfinished bar, missing samples, contrary score
alone or pullback inside that range cannot cancel the scenario. Retirement
never authorizes an opposite entry.

An actual opposing micro turn prevents a new continuation forecast while a
retracement is underway. Extension alone does not block a strong trend.
Existing exhaustion, barriers and model safety checks remain. This changes
prospective selection and lifecycle; it does not claim a new learned model
or guarantee early predictions or a higher measured trading win rate.

The independent Subanalista still requires its own prior trend, structural
break and closed-bar follow-through. A missing distant target no longer
silences this advisory warning. Target information is optional and does not
authorize an entry. Fresh quote-check time is shown so current observation
can be distinguished from a stalled feed. The module remains independent
of the scenario and of the three totals.

New scenarios require fresh quotes. No order authorization was added, and
the mobile start control continues to disable the demo pilot before starting
analysis. The three totals and their observational average are unchanged.

Validation: complete Node regression suite, production Next build/type check,
archived quote replay for lifecycle sensitivity, and the Windows installation,
upgrade, tray recovery and rendered overlay workflow. Historical lifecycle
replay holds original older-version forecasts fixed; it cannot measure the
new version's forecast selection or actual operation results. Confirmed breaks
can later recover, so structural retirement does not eliminate losses.
