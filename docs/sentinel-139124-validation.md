# Sentinel 13.9.124

Revalidates an automatic entry immediately before its first physical dispatch using the existing passive quote and the analyst's already computed final observation. It does not run a second forecast, request broker data, scan the page, wait for another quote or add any timer. The existing three-second post-expiry analyst interval and original first-click deadlines are unchanged.

The runtime publishes a small immutable same-tick observation before its immediate entry callback, independently of the previous dashboard frame. An unclicked automatic batch retains the issuing observation. The existing physical-click validation revokes it only when a newer fresh final observation confirms the opposite direction in the same provider/asset/strategy/duration, or a fresh received quote crosses the original confirmed reversal's actual invalidation boundary. That boundary is the existing fast-V invalidation price or the confirmed higher-low/lower-high turn. Continuation receives no invented boundary. Neutral, incomplete, stale, future and different-context observations do not create a new readiness gate.

A revoked signal is consumed once, stays skipped even if price subsequently recovers, and waits for an actually new analyst signal. It does not become a broker order, LOSS, stop event or Martingale progression/reset. Once the first physical attempt has started, the existing sibling-click, unknown-acknowledgement and settlement lifecycle remains authoritative. CALL-only/PUT-only cadence is independent and unchanged. The check is immediately before the existing Playwright invocation; it cannot eliminate market changes during the browser's own actionability/dispatch interval or change an already open trade.

Validation: all 675 registered release tests passed, including 12 new tests. Controlled IQ Option/Exnova executor races change the current observation or quote while native controls are being resolved and verify zero click invocations, no fake result, no replay, retained Martingale level, and immediate eligibility of a genuinely new signal. Other cases cover same-tick execution with an old dashboard, neutral observations, both reversal directions, context/future/freshness isolation, independent fixed-direction modes, and preserved sibling batches. The tests use mocked browser controls and place no live broker orders.

Paired full-decision replay against 13.9.123 preserved all entries/outcomes across 70 overlapping settings. A separate physical-dispatch replay uses the received prefix at assumed 0/300/600ms dispatch delays: all 105 settings preserved the same outcomes and none triggered this new revocation path on that recording. Both replays share one 179-second price trace and are not independent trials. They demonstrate preservation on the available recording, not improved live accuracy. The changed behavior is demonstrated by controlled races; no live cancellation-rate or accuracy improvement is established.
