# DevinX Laser Agent\n\nEsta pasta é propositalmente independente do build Next.js/Vercel.\n\n## V0\n\nA primeira versão do Agent é **somente diagnóstico local**:\n- envia `PING` para o LightBurn em `127.0.0.1:19840`;\n- envia `STATUS`;\n- escuta a resposta local em `127.0.0.1:19841`;\n- não recebe comandos da internet;\n- não possui START, STOP, PAUSE ou FRAME;\n- não controla Windows, mouse ou teclado;\n- não executa comandos de sistema.\n\nIsso valida a ponte local sem criar risco desnecessário antes do pareamento, autenticação e autorização estarem prontos.\n\n## Build local\n\nRequer .NET 8 SDK:\n\n```powershell\ndotnet run --project .\\laser-agent\\DevinXLaserAgent.csproj\n```\n\nO Agent definitivo ganhará UI mínima de bandeja, atualização assinada e conexão outbound autenticada somente depois da camada de segurança estar pronta.\n
